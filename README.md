# bestrom_ota

OTA JSON catalog for BestROM (VoltageOS-based).

- Branch `16` = Android 16 / BestROM A16 channel
- URL shape used by Updater: `https://raw.githubusercontent.com/Mohithash/bestrom_ota/16/{device}.json`
- Device codename file, e.g. `peridot.json`

Placeholder entries have empty/zero size so the app can fetch JSON without offering a real install until a real zip is published.
